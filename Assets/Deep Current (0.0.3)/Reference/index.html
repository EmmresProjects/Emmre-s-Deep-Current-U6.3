PROJECT OVERVIEW & CREDITS

ABOUT

PROJECT MISSION

DEEPCURRENT is basically a personal project to experiment if it’s possible to create certain control mechanics fit for mobile games.

WHAT WE DID & LEARNED

We tested twin-stick controls on mobile where aiming with the right stick automatically shoots your weapon. From testing on phones and tablets, we learned that clear visual hints (like the aiming target and fire ring) and giving players the choice between fixed or floating joysticks make mobile controls feel smooth, precise, and comfortable.
